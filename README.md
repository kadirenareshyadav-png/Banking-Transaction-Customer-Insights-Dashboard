The Banking Transaction & Customer Insights Dashboard is an interactive Power BI project developed to analyze customer demographics, banking transaction behavior, customer segmentation, and profitability and risk indicators.

The dashboard transforms raw banking transaction data into meaningful insights using data cleaning, data transformation, DAX calculations, and interactive visualizations.

The main objective of this project is to understand customer behavior, identify transaction patterns, analyze customer segments, and support data-driven business decisions.


🎯 Project Objectives

Analyze customer demographics based on gender and location.

Understand banking transaction patterns and customer behavior.

Identify customer segments using RFM analysis.

Analyze customer account balances and transaction amounts.

Identify potential high-risk customers.

Generate meaningful business insights through interactive dashboards.

🛠️ Tools & Technologies

Power BI – Dashboard development and data visualization.

Power Query – Data cleaning and transformation.

DAX – Measures, calculated columns, and KPIs.

Excel / CSV – Dataset preparation and data handling.
